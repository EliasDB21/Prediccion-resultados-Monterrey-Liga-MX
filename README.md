# Prediccion-resultados-Monterrey-Liga-MX
Se utilizaron datos historicos del año 2016 en adelante de la LIGA MX para generar predicciones de resultados por el club de futbol Monterrey en la temporada 2024-2025. Se alcanzó una exactitud del 93 % en comparación con resultados de partidos reales utilizando el algoritmo Random Forest.

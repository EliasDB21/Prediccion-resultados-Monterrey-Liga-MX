# Prediccion-resultados-Monterrey-Liga-MX
Se utilizaron datos historicos del año 2016 en adelante de la LIGA MX para generar predicciones de resultados por el club de futbol Monterrey en la temporada 2024-2025. Se alcanzó una exactitud del 93 % en comparación con resultados de partidos reales utilizando el algoritmo Random Forest. 

📊 Tecnologías y Herramientas Utilizadas

Lenguaje: Python

Librerías: pandas, numpy, seaborn, matplotlib, scikit-learn, RandomForestClassifier

Plataforma: Google Colab

Fuente de Datos: [(https://www.kaggle.com/datasets/gerardojaimeescareo/ligamx-matches-2016-2022/data)]


🔍 Metodología

Carga y exploración de datos: Se procesan los datos abiertos de la liga MX de la temporada 2016 hasta la temporada 2024. Se filtran los partidos del Club de fútbol Monterrey. 

Limpieza y transformación: Se eliminan valores nulos y se normalizan las variables.

Entrenamiento del modelo: Se implementa un modelo de machine learning de clasificación con Random Forest.

Evaluación y validación: Se mide el rendimiento con métricas como accuracy y precision.


📈 Resultados

Se logró una precisión del 93% en la predicción de resultados del club de Fútbol Monterrey (Rayados) en la temporada 2024-2025.

Se generaron visualizaciones que permiten interpretar mejor los datos.
